Building blocks for the three steps of the Decision Maker: apartments, preferences and results. Rules, field names and states follow docs/data-model.md. All values are placeholder data. The scores in step 3 are calculated with test profile A, but they only illustrate the layout and are not reference results.

3 · STEP: PREFERENCES

Set the preference profile

Order: hard limits, then furnishing, then reference values, then pairwise comparisons. Furnishing comes before the comparisons because "neutral" switches E15 off and reduces 21 questions to 15. There are no default values anywhere.

.ref-table

Reference values

For each criterion: the value that earns full points and the worst value you would still accept (zero points). Values in between get points proportionally. These stay fixed while you compare, so adding an apartment never changes another apartment's score.
