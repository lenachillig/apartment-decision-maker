# Apartment Decision Maker

A student project to develop a decision support website for comparing apartments and shared flats.

## Current status

Initial website structure with HTML, CSS, and JavaScript. The decision-making functionality will be added later.

## Run locally

Open `index.html` in a web browser.

## Collaboration

Team members work on separate branches and propose changes using pull requests.

## Data

Only fictional or approved, anonymized data may be committed to this repository. Do not commit sensitive data or credentials.
